# 规格：JSON 数据编辑器

- 状态：已实现
- 创建日期：2026-08-21

## 用户场景

用户需要构造一份结构化 JSON 数据（用于后续生成 PDF），但不希望手写 JSON 文本。通过可视化编辑器逐节点搭建数据，实时看到最终 JSON。

## 功能需求

- FR-1：支持六种数据类型：字符串、数字、布尔、null、对象、数组，任意节点可随时切换类型。
- FR-2：支持任意层级嵌套：数组可包含对象/数组，对象可包含数组/对象。
- FR-3：对象的字段名可输入、可修改；字段和数组元素可增删。
- FR-4：右侧实时输出格式化 JSON，支持复制到剪贴板和下载为 `data.json`。
- FR-5：无需登录，打开即用。

## 验收标准

- AC-1：`pnpm -C web build && pnpm -C web lint` 通过。（对应 FR-1~FR-5）
- AC-2：页面中任一节点可切换六种类型，切换后结构正确反映在 JSON 输出中。（对应 FR-1、FR-2）
- AC-3：在对象中新增字段并输入字段名与值、在数组中添加对象元素，JSON 输出同步正确。（对应 FR-2、FR-3）
- AC-4：点击「复制」后剪贴板内容与输出面板一致；点击「下载」得到合法 JSON 文件。（对应 FR-4）
- AC-5：含 `null`、数字（含小数）、布尔的 JSON 数据加载进编辑器不报错，且 `toJson(fromJson(x))` 与原值深度相等（类型不丢失）。（对应 FR-1）

## 非目标（Out of Scope）

- JSON 文本直接导入/粘贴解析。
- 撤销/重做、多人协作、持久化存储。
