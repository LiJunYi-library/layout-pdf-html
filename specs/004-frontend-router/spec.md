# 规格：前端路由与布局预览页（TanStack Router）

- 状态：已实现
- 创建日期：2026-08-21

## 用户场景

用户在编辑器完成 JSON 数据后，想先看看后端 agent 会把这份数据排成什么样的版面结构（哪些变表格、哪些变列表、分节标题是什么），再决定要不要生成 PDF。需要一个「布局」页面展示这个结构预览，并能随时返回编辑。

## 功能需求

- FR-1：前端引入 `@tanstack/react-router`，至少两条路由：`/`（数据编辑器，现有主页）、`/layout`（布局预览页）。
- FR-2：主页提供「查看布局」按钮跳转到 `/layout`；布局页提供返回编辑器的入口。
- FR-3：布局页进入时调用 `POST /api/layout`（提交当前编辑器数据），把返回的 DocumentSpec 渲染为可读预览：标题、键值对、编号列表、表格、分节层级。
- FR-4：布局页有加载中与错误提示状态；请求失败时展示错误信息而非白屏。
- FR-5：路由切换不丢失编辑器中的数据（两页共享同一份编辑状态）。
- FR-6：所有服务端请求统一通过 `@tanstack/react-query` 发起，请求函数集中在 `web/src/api.ts`。

## 验收标准

- AC-1：`pnpm -C web build && pnpm -C web lint` 通过。（对应 FR-1~FR-5）
- AC-2：主页点击「查看布局」URL 变为 `/layout` 并显示布局预览；布局页可返回 `/`。（对应 FR-2）
- AC-3：编辑包含表格/列表/键值对结构的数据后进入布局页，预览中出现对应的表格、编号列表与键值对。（对应 FR-3）
- AC-4：后端不可达时布局页显示错误提示。（对应 FR-4）
- AC-5：从 `/layout` 返回 `/` 后，编辑器内容与离开前一致。（对应 FR-5）

## 非目标（Out of Scope)

- 布局页直接渲染/预览真实 PDF。
- 路由懒加载、URL 携带数据、更多页面。
- 文件式路由（采用代码式路由，结构简单）。
